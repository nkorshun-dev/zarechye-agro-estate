# Агроусадьба «Заречье»

Сайт вымышленной агроусадьбы в Браславском районе: четыре домика, календарь занятости, расчёт цены по датам, доп. услуги и бронирование в три шага.
**Демо-проект для портфолио: бизнес вымышленный, бронирования никуда не отправляются.**

Демо: https://nkorshun.dev/zarechye/.

## Скриншоты

_Добавьте в `docs/`: главная, страница домика с календарём, бронирование (шаг 1), экран успеха._

## Возможности

- Календарь занятости с ценой на каждый день, выбор диапазона с клавиатуры (стрелки, PageUp/PageDown, Home/End).
- Нельзя выбрать диапазон через занятую ночь; минимум ночей (выходные и праздники — 2, лето и Новый год — 3) с понятной подсказкой.
- Цена: будни, выходные (пт–сб), праздники Беларуси (включая Радуницу), сезоны, фиксированная цена на Новый год, доплата за гостей, дети до 5 лет бесплатно, скидка 10% за 7+ ночей.
- Бронь в три шага, итог и предоплата 30%, экран успеха и файл `.ics` для календаря.
- Параметры бронирования лежат в URL, ссылкой можно поделиться.
- Брони пользователя сохраняются в localStorage и блокируют даты.

## Стек

React 19, Vite, TypeScript (strict), React Router, CSS Modules, Vitest, oxlint. Без UI-библиотек и без библиотек календаря.

## Архитектура

- **Даты** (`src/lib/dates.ts`): дата — строка `ГГГГ-ММ-ДД`, арифметика через UTC, «сегодня» считается по Europe/Minsk. Ночи = дни от заезда до выезда (день выезда не считается). Так нет сдвигов из-за часового пояса гостя и перехода на летнее время.
- **Занятость** (`src/lib/availability.ts`): «чужие» брони генерируются детерминированно от seed (домик + месяц) на 5 месяцев вперёд и не меняются при перезагрузке. К ним добавляются брони пользователя из localStorage (`zarechye:bookings`). Логика выбора диапазона (`selectDay`) — чистая функция.
- **Цена** (`src/lib/pricing.ts`): чистые функции с тестами. Все числа и правила — в `src/data/pricing.ts`, цены домиков — в `src/data/houses.ts`.
- **URL** (`src/hooks/useBooking.ts`): `?h=домик&in=2026-07-10&out=2026-07-13&a=2&c=3,7&p=1`. Битые значения отбрасываются.

## Где менять цены и сезоны

| Что | Где |
| --- | --- |
| Цены будни/выходные/Новый год по домикам | `src/data/houses.ts` |
| Коэффициенты сезонов, праздники, Новый год, наценки, скидка, предоплата, минимальные ночи | `src/data/pricing.ts` |
| Доп. услуги и их цены | `src/data/extras.ts` |
| Контакты и правила | `src/data/estate.ts` |


## Деплой на Netlify

1. Залейте проект в Git-репозиторий и подключите его в Netlify («Add new site» → «Import from Git»).
2. Настройки подхватятся из `netlify.toml`: команда `npm run build`, папка `dist`.
3. Редирект `/* → /index.html 200` (SPA) уже настроен в `netlify.toml` и `public/_redirects`, прямые ссылки вида `/houses/rybatsky` работают.
